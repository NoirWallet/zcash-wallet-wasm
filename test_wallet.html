8b. Get Account HD Index

What is HD Index?
The HD (Hierarchical Deterministic) index is the account number used when deriving this account from a mnemonic phrase. For example, if you created an account with HD index 0, that means it's the first account derived from the mnemonic.

Returns: The HD index number, or "Not available" if the account was imported (not derived from a mnemonic).

9. PCZT Shield (Shield Transparent Funds)

What is PCZT Shield?
Shields all transparent funds in an account by moving them to the Orchard shielded pool. This is useful for privacy - transparent transactions are public like Bitcoin, while shielded transactions are private.

PCZT Steps:

10. Shield Funds (Direct Method)

Alternative to PCZT Shield
This method shields transparent funds directly without using PCZT format. It creates and broadcasts the shielding transaction in one step.

Note: This method requires your mnemonic phrase to derive spending keys. The keys are only used temporarily in memory and are never stored.

Important: Make sure to use the same mnemonic that was used to create the account. The account HD index is assumed to be 0 (the first account from this seed).
